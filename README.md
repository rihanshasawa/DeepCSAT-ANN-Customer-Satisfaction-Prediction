# DeepCSAT: E-Commerce Customer Satisfaction Score Prediction using ANN

## Project Overview

This project focuses on predicting Customer Satisfaction (CSAT) scores using Deep Learning Artificial Neural Networks (ANN) on customer support interaction data from an e-commerce platform.

The project demonstrates an end-to-end AI Engineering workflow including:
- data preprocessing,
- feature engineering,
- ANN model development,
- optimization strategies,
- evaluation,
- deployment concepts,
- and business insight generation.

---

# Business Problem

Customer Satisfaction (CSAT) is one of the most important performance indicators in the e-commerce industry.

Poor customer support can lead to:
- customer churn,
- negative reviews,
- reduced loyalty,
- and revenue loss.

This project aims to proactively predict customer satisfaction scores using Deep Learning techniques to improve customer support operations and enhance customer experience.

---

# Project Objectives

- Clean and preprocess customer interaction data
- Engineer meaningful predictive features
- Build and optimize an ANN model
- Predict CSAT scores effectively
- Generate business insights
- Demonstrate AI Engineering workflow
